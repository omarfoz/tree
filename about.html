# الاسم الجيل تاريخ الإمارة

منهجية الاستخراج

المصدر: تم استخراج البيانات من الموقع الرسمي لصندوق أسرة السويلم (tree.alswailem.app).

طريقة الاستخراج:

  1. تحميل ملف HTML الخاص بعارض الشجرة (v10.html)
  2. استخراج بيانات ENTS — مصفوفة JSON تحتوي على (x, y, عرض، ارتفاع، نص) لكل تسمية ظاهرة على الشجرة
  3. تصنيف التسميات إلى أسماء / موصلات (بن/بنت) / غير أسماء (عناوين/أرقام)
  4. تطبيع النص العربي لأغراض البحث (إزالة التشكيل، توحيد الألف، إلخ)
  5. حساب تكرار الأسماء مع ملاحظة أنّ التسميات هي مواضع نصية وليست سجلات أفراد

القيود:

  • لا توجد علاقات أب-ابن في البيانات المستخرجة
  • لا توجد معرفات فريدة للأفراد
  • التوزيع حسب الجيل والفرع هو إجمالي رسمي، وليس مرتبطاً بكل فرد
  • قد يظهر الاسم كأب أو جد وليس كاسم أول
